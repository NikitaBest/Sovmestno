Техническое задание на разработку мини-приложения в Telegram для проверки совместимости
1. Общее описание
Мини-приложение в Telegram предназначено для проверки совместимости двух людей на основе их дат и времени рождения. Пользователи вводят данные (дата и время рождения для себя и партнера), после чего приложение отправляет запрос к нейросети для расчета совместимости и отображает результаты в процентах по нескольким категориям, а также итоговый процент совместимости. Приложение должно быть интуитивно понятным, визуально привлекательным и интегрированным с Telegram Web App API.
2. Цели и задачи
Цель: Создать мини-приложение в Telegram, которое позволяет пользователям проверять совместимость с партнером на основе астрологических и нумерологических данных.
Задачи:
Разработать интерфейс для ввода дат и времени рождения двух людей.
Интегрировать приложение с Telegram Web App API для взаимодействия с Telegram.
Отправлять запросы к нейросети с использованием заданного промта для расчета совместимости.
Отображать результаты в виде процентов по категориям с визуальными элементами (прогресс-бары).
Обеспечить валидацию входных данных и обработку ошибок.
Сделать приложение адаптивным и удобным для использования на мобильных устройствах.
3. Функциональные требования
3.1. Основные функции
Ввод данных:
Пользователь вводит дату рождения (ДД.ММ.ГГГГ) и время рождения (ЧЧ:ММ) для себя и партнера через формы.
Формат ввода: текстовые поля с валидацией (например, маска ввода или проверка корректности).
Отправка запроса:
Приложение формирует запрос к нейросети, используя промт (см. раздел 3.3).
Запрос отправляется через сервер (например, Flask) или напрямую через API нейросети.
Отображение результатов:
Результаты отображаются в виде процентов по категориям:
Зодиакальная совместимость (30% веса).
Совместимость по стихиям (20% веса).
Нумерологическая совместимость (20% веса).
Эмоциональная совместимость (20% веса).
Интеллектуальная совместимость (10% веса).
Итоговая совместимость (средневзвешенный процент).
Визуализация: прогресс-бары для каждой категории с цветовой индикацией (например, зеленый для высоких процентов, красный для низких).
Краткое текстовое описание совместимости (опционально, если поддерживается нейросетью).
Интеграция с Telegram:
Использование Telegram Web App API для получения user_id и отображения в Telegram.
Кнопка "Поделиться результатом" для отправки результатов в чат.
3.2. Пользовательский интерфейс
Экран 1: Ввод данных:
Заголовок: "Проверьте вашу совместимость".
Два блока для ввода данных:
"Ваши данные": поля для даты (ДД.ММ.ГГГГ) и времени (ЧЧ:ММ).
"Данные партнера": аналогичные поля.
Кнопка "Рассчитать совместимость".
Валидация: предупреждение при некорректном формате (например, "Введите дату в формате ДД.ММ.ГГГГ").
Экран 2: Результаты:
Заголовок: "Результаты совместимости".
Список категорий с процентами и прогресс-барами.
Итоговый процент совместимости (выделен крупным шрифтом).
Кнопка "Поделиться" для отправки результатов.
Кнопка "Попробовать снова" для возврата к вводу данных.
Дизайн:
Использовать Tailwind CSS для стилизации.
Адаптивный дизайн для мобильных и десктопных устройств.

3.3. Промт для нейросети
Промт, используемый для отправки запроса к нейросети, должен быть следующим:
You are an expert in astrology and numerology. Your task is to calculate the compatibility between two people based on their birth dates and times. The input data is:

- Person 1: Date of birth = {DD.MM.YYYY}, Time of birth = {HH:MM}
- Person 2: Date of birth = {DD.MM.YYYY}, Time of birth = {HH:MM}

Calculate compatibility in the following categories:
1. Zodiac compatibility (based on zodiac signs, 30% weight)
2. Elemental compatibility (based on fire, earth, air, water elements, 20% weight)
3. Numerological compatibility (based on birth date numbers, 20% weight)
4. Emotional compatibility (based on time of birth or ascendant, 20% weight)
5. Intellectual compatibility (based on zodiac or arbitrary factors, 10% weight)

Provide the result in the following JSON format:
{
  "zodiac_compatibility": <percentage>,
  "elemental_compatibility": <percentage>,
  "numerological_compatibility": <percentage>,
  "emotional_compatibility": <percentage>,
  "intellectual_compatibility": <percentage>,
  "overall_compatibility": <weighted average percentage>
}

Each percentage should be an integer between 0 and 100. Use astrological and numerological principles to make the results realistic and engaging. If precise calculations are not possible, use reasonable approximations based on zodiac signs, elements, and birth numbers. Ensure the overall compatibility is a weighted average of the categories.
